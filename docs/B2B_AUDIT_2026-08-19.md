# TalkPilot Teams — B2B Product Audit (2026-08-19)

Code-grounded audit of the B2B product (Command Center + Teams layer) against the B2C apps,
the in-repo Teams specs (`talkpilot-app/docs/TEAMS_*.md`), and the sales-tech market.
Companion deliverable: two dashboard redesign concepts ("Boardroom" light / "Flight Deck"
obsidian) on the design canvas, using the D-047 brand.

- Audit page: https://claude.ai/code/artifact/6b59e99c-05c3-4a28-8af2-2c4b40fcd53c
- Mockup canvas: https://claude.ai/code/artifact/34819487-8284-45bc-9fde-4ed5e23edb9e

## Verdict

The core is genuinely differentiated — live coaching graded against the same playbook that
coached it, a KB-grounded truth audit, and a trust layer enforced in Postgres RLS. But the
Command Center is ~40% of the product the spec describes, and its IA hides its own depth:
the org's entire setup surface (8 tabs, 3 AI ingestion flows, 59% of the code in
`admin/page.tsx`) sits behind one "Admin" gear while the four top-level nav items are the
thinnest pages in the app. Biggest commercial risk: nothing in the dashboard proves value to
the person who signs the renewal (no adoption view, no exports, no outcome correlation).

## Strengths to keep

- The closed loop (define → coach live → score → refine) — the moat vs. Gong/Chorus.
- Trust layer in RLS (`scores_only` / `flagged_moments` / `full_transcripts`); reps always
  see their own scorecards.
- Team DNA (transcripts → tone/phrases/objections/playbook) — killer self-serve onboarding.
- Members-tab readiness gate; AskPanels; accept-invite platform-detection flow.

## Backend built, UI missing (cheapest roadmap)

| Capability | Backend | UI |
|---|---|---|
| Teams / sub-team management | `org_teams` | none (can't create/rename/assign) |
| Pushed focus areas | `org_focus_assignments` | none |
| Coaching comments | `coaching_comments` | write-only, never readable |
| Audit log | `org_audit_log` | none |
| Org modes / prompt overrides | `org_modes`, `org_prompt_templates` | none |
| CRM sync | `crm-sync` + OAuth callbacks | none |
| Practice grade roll-up | `org_practice_completions` | none |
| Leaderboard, rep trends | data present | none |
| Retention settings | spec'd (open decision) | none |

## Gaps vs. B2C

- No dark mode (B2C defaults dark, D-147); zero brand fonts (palette landed, type didn't —
  rebrand checklist §5); three conflicting color systems (dead Tailwind token, CSS vars,
  raw `teal-*` utilities).
- Practice assignment limited to 10 stock scenarios; B2C generates scenarios from calendar/
  real calls — B2B should generate from the org's playbook + objection library.
- No adoption/engagement view (B2C has streaks/stats); scorecards lack a one-line takeaway.

## Market gaps (Gong/Chorus/Salesloft bar)

- **P0**: self-serve org creation (today: "No org membership found" dead end); adoption &
  ROI view; password reset + Google OAuth + auth guards (only `/` checks a session);
  IA redesign; finish the coaching loop.
- **P1**: teams CRUD + manager scoping + leaderboard; rep page per spec (name, sparklines,
  focus areas, comments); all-sessions list with filters; Slack/email breach alerts
  (`slack-notifications` exists); org-specific practice generation; brand completion.
- **P2**: Trust Center page (visibility + retention + audit log + disclosure — a sales
  asset); CRM outcome correlation; exports/scheduled reports; SSO/SAML + SCIM.

## Bugs found

- Playbook activation runs `update({status:"draft"})` across all org playbooks —
  resurrects archived ones; Team DNA inserts `status:"active"` without deactivating others
  (two active playbooks possible).
- Overview 4-week trend computed from the recent-50 slice — wrong for orgs >50 calls/30d.
- Objections/Playbooks accept `.pdf` but read it as text (binary garbage to extractor).
- "Check RESEND_API_KEY secret" surfaced to customers; alexis@ hardcoded as escalation.
- `/insights` passes all scorecard ids in a GET query string (URL-length ceiling).
- Tone-chip regex round-trip is lossy; no focus rings; no delete confirms; no error
  boundaries; no pagination (team query hits PostgREST's silent 1000-row default); admin
  and scorecard tabs aren't URL-addressable.
- Sibling repo `talkpilot-ai-coach` is an abandoned Lovable extension scaffold with a
  committed `.env` — archive it.

## Proposed IA (basis of the mockups)

Sidebar, every screen URL-addressable:
**Home** (attention feed, pulse, adoption) · **Calls** (all sessions + scorecard) ·
**Team** (roster, teams CRUD, leaderboard, rep profile) · **Coaching** (focus areas,
comment threads, practice) · **Insights** (objections, truth-audit topics, digests,
outcomes) · **Playbook** (playbooks, objections, knowledge, voice, Team DNA) ·
**Settings** (org, members, billing, integrations, Trust Center).
